# Интерактивная 3D-модель лица на чистом JavaScript (Vanilla JS)

Высокопроизводительная интерактивная 3D-модель человеческого лица, визуализируемая в реальном времени с использованием чистого ванильного JavaScript и HTML5 Canvas 2D API. Проект работает абсолютно без внешних библиотек, фреймворков и 3D-движков (без Three.js, Babylon.js и без WebGL зависимостей).

## Основные возможности

- **Анатомическая 3D-топология лица**: основана на канонической модели лица человека с 468 вершинами и 898 треугольными полигонами.
- **3D-движок на чистом Vanilla JS**:
  - Перспективная проекция камеры с учетом фокусного расстояния и глубины.
  - Матрицы 3D-вращения по углам Эйлера и кватернионам.
  - Вычисление нормалей к плоскостям треугольников для направленного освещения по Ламберту.
  - Глубинная сортировка (Painter's algorithm) для корректного наложения полигонов.
  - Отсечение невидимых граней (back-face culling) для переключения между сплошной поверхностью и полупрозрачной голограммой.
- **Три основных режима визуализации**:
  1. **Точки (вершины)**: 468 светящихся неоновых точек с масштабированием по глубине и акцентным выделением глаз, губ и контура носа.
  2. **Проволочный каркас (рёбра)**: сглаженные линии треугольной сетки с регулируемой толщиной и неоновым свечением.
  3. **Полигоны (треугольные грани)**: полупрозрачные глубинно-отсортированные треугольники с динамическим диффузным освещением.
- **Интерактивное управление камерой (Orbit Controls)**:
  - Вращение левой кнопкой мыши / одним пальцем на сенсорном экране с плавной инерцией.
  - Масштабирование колесиком мыши или жестом pinch-to-zoom.
  - Панорамирование правой кнопкой мыши или Shift + левая кнопка.
  - Двойной клик или клавиша `R` — сброс камеры в исходное положение.
  - Пробел — включение/выключение плавного авто-вращения.
- **5 встроенных цветовых Sci-Fi палитр**:
  - *Cyberpunk Neon* (бирюзовый и неоново-розовый)
  - *Matrix Emerald* (изумрудно-зеленый и лаймовый)
  - *Electric Sci-Fi Blue* (электрический синий и ледяной)
  - *Solar Amber* (янтарное золото и оранжевый)
  - *Titanium Silver* (минималистичный титановый белый)
- **Поддержка экранов Retina / High-DPI**: четкая графика на любых разрешениях экрана.
- **Полная автономность**: 100% офлайн работа в любом браузере без обращения к сети.

## Структура проекта

```
evaline-face/
├── index.html           # Полноэкранный канвас и плавающий HUD интерфейс
├── css/
│   └── style.css        # Футуристический киберпанк дизайн и стилизация HUD
├── js/
│   ├── faceData.js      # Канонические 3D координаты (468 вершин, 898 треугольников)
│   ├── math3d.js        # 3D математика: векторы, матрицы, проекция, нормали
│   ├── renderer.js      # Многослойный канвас-рендерер (точки, линии, полигоны)
│   ├── controls.js      # Управление мышью и тачем с инерцией и зумом
│   └── app.js           # Главный контроллер, цикл рендеринга и события UI
└── docs/
    ├── README.en.md     # Документация на английском языке
    ├── README.ru.md     # Документация на русском языке
    └── README.uk.md     # Документация на украинском языке
```

## Запуск проекта

1. Откройте файл `index.html` напрямую в любом современном браузере, либо:
2. Запустите локальный сервер:
   ```bash
   python3 -m http.server 8080
   # или
   npx serve .
   ```
3. Перейдите по адресу `http://localhost:8080`.
