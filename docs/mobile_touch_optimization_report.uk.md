# Звіт: Оптимізація під мобільні смартфони та сенсорні пристрої

## Огляд
У цьому технічному звіті зафіксовано результати оптимізації сенсорного керування, адаптивності UI та продуктивності для мобільних смартфонів (iOS Safari, Android Chrome, mobile Firefox) та планшетів.

---

## 1. Архітектура сенсорних жестів (`js/controls.js`)

- **Скінченний автомат мультитачу:**
  - **Один палець (1 Touch):** Обертання 3D-моделі навколо центру мас $(0, 0, 0)$.
  - **Два пальці (2 Touch):** Масштабування (Pinch-to-zoom) за евклідовою відстанню:
    $$\text{dist} = \sqrt{(x_0 - x_1)^2 + (y_0 - y_1)^2}$$
  - **Плавний перехід між жестами:** При відпусканні одного пальця під час зуму координати `lastMouseX` та `lastMouseY` перехоплюються без ривків та стрибків.
- **Захист від системних жестів браузера:**
  - `touch-action: none` на `#faceCanvas` запобігає прокручуванню сторінки та свайп-оновленню.
  - Слухачі `{ passive: false }` з `e.preventDefault()` на `touchmove` та `touchstart`.
  - Додано обробник `touchcancel` для скидання стану при виклику шторки iOS / вхідному дзвінку.

---

## 2. Мобільна продуктивність та енергоефективність (`js/renderer.js`)

- **Обмеження DPR до 2.0:** На смартфонах із `devicePixelRatio = 3.0` або `3.5` рендеринг Canvas 2D обмежується значенням `2.0`, що забезпечує ідеальну чіткість Retina та захищає смартфон від перегріву й розряджання батареї.
- **Відсутність сміттєвих об'єктів (Zero Allocation):** Попередньо виділені буфери та кеш кольорів виключають мікрозависання від збирача сміття на мобільних процесорах.

---

## 3. Мобільний UI та розміри клікабельних зон (`css/style.css`, `index.html`)

- **Мінімальний розмір кнопок 44px:** Усі елементи керування (`.hud-main-trigger`, `.hud-btn`, `.toggle-control`) відповідають стандарту WCAG 2.1 AA для сенсорних екранів ($\ge 44 \times 44\text{px}$).
- **Підтримка вирізів екранів (Safe Area Insets):** Використання CSS-змінних `env(safe-area-inset-top)` та `env(safe-area-inset-bottom)` для коректного відображення на iPhone з чілкою / Dynamic Island.
- **Адаптивна панель:** На екранах $< 600\text{px}$ панель займає `width: calc(100vw - 24px)` з нативним тач-скролом (`-webkit-overflow-scrolling: touch`).

---

## 4. Верифікація
- Протестовано у браузері через Puppeteer на мобільній роздільній здатності (390×844).
- Підтверджено стабільну частоту 60 FPS та відсутність ривків.
