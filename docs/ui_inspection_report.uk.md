# Звіт про інспекцію інтерфейсу користувача (UI) та візуального оформлення

**Цільовий проект:** `evaline-face` (`index.html`, `css/style.css` та пов'язані модулі інтерфейсу)  
**Дата інспекції:** 02.09.2026  
**Область перевірки:** Адаптивність до мобільних пристроїв (смартфони, планшети, 4K-монітори), Доступність (WCAG 2.1/2.2 AA) та Візуальне шліфування (HUD-стилістика, гласморфізм, анімації, елементи керування).

---

## Короткий зміст

Проект **3D Neural Face Mesh** представляє візуально виразний інтерфейс у стилі кіберпанк-HUD, створений повністю на чистих веб-технологіях (HTML5 Canvas 2D, CSS3, ES6 JavaScript) без зовнішніх 3D-бібліотек. Естетика матового скла (гласморфізм), темна тема та неонові світлові акценти гармонійно підкреслюють концепцію нейромережевої сітки обличчя.

Проте детальний аудит виявив низку критичних та помірних недоліків:
1. **Адаптивність:** Серйозне переповнення області перегляду на смартфонах (<480px) у нижній панелі дій, відсутність урахування безпечних зон (`safe-area-inset`) для вирізів екранів та жестових смуг, стиснутий інтерфейс в альбомній орієнтації телефонів та мініатюрні елементи з фіксованими пікселями на 4K-дисплеях.
2. **Доступність:** Критичне порушення WCAG, за якого приховані чекбокси (`display: none`) роблять усі 7 перемикачів режимів рендерингу на 100% недоступними для клавіатурної навігації та скрінрідерів; відсутність видимих стилів фокусу (`:focus-visible`); нестилізовані повзунки у Firefox; відсутність підтримки налаштування зменшення руху (`prefers-reduced-motion`).
3. **Візуальне шліфування:** Стандартні системні емодзі дисонують із науково-фантастичною типографікою, смуга прокручування в панелі керування має стандартний сірий вигляд ОС, у повзунків відсутнє підсвічування заповненої частини доріжки, а плашки мають звичайні заокруглення замість технологічних скошених кутів кіберпанк-інтерфейсу.

## 2. Аудит доступності (a11y)

### 2.1 Критичні та високі порушення

1. **Приховування чекбоксів через `display: none`:**
   - **Файл:** `css/style.css:315-317`
   - **Проблема:** `.toggle-control input { display: none; }` повністю виключає всі 7 чекбоксів із порядку фокусування табуляцією (Tab) та дерева доступності.
   - **Наслідки:** Користувачі, які користуються лише клавіатурою або екранними читцями, не можуть увімкнути/вимкнути жоден режим рендерингу (Точки, Сітка, Грані, Відсікання задніх граней, Сяйво, Пульсація, Автоповорот).
   - **Рішення:** Застосувати патерн візуального приховування (`position: absolute; opacity: 0; width: 1px; height: 1px; pointer-events: none;`) та додати індикацію фокусу для `.toggle-slider`.

2. **Відсутність видимих станів фокусу (`:focus-visible`):**
   - **Файл:** `css/style.css`
   - **Проблема:** У кнопок `.hud-btn` оформлено лише `:hover`, а стилі фокусу відсутні. Повзунки (`input[type="range"]`) містять `outline: none;` без альтернативної індикації фокусу.
   - **Наслідки:** Під час переходу по елементах за допомогою клавіатури користувач не бачить поточної точки взаємодії.

3. **Відсутність семантичних ARIA-атрибутів:**
   - `<canvas id="faceCanvas">`: Потрібні `role="img"` та `aria-label="Інтерактивна 3D-модель нейронної сітки обличчя"`.
   - `#panelToggle`: Потрібні `aria-expanded="false"`, `aria-controls="controlPanel"` та `aria-label="Перемкнути панель налаштувань"`.
   - `#controlPanel`: Потрібні `role="region"` та `aria-label="Матриця керування 3D"`.
   - Повзунки налаштувань (`#sliderPointSize` тощо): Відсутні `aria-label` або `aria-labelledby`, через що екранний читець читає тільки числове значення без назви параметра.
   - `#themeSelect`: Заголовок групи оформлено звичайним `<div>`, відсутній `<label for="themeSelect">` або `aria-label="Колірна палітра"`.

### 2.2 Помірні та дрібні зауваження

4. **Контрастність неактивних елементів (WCAG 1.4.11):**
   - Фон вимкненого перемикача: `rgba(255, 255, 255, 0.12)` на темному тлі дає контрастність ~1.8:1, що нижче за необхідний поріг 3:1.
   - Доріжка повзунка: `rgba(255, 255, 255, 0.15)` ледь помітна.
5. **Відсутність обробки переваги зменшення руху (`prefers-reduced-motion`):**
   - Нескінченне обертання кільця логотипа (`animation: rotateSpin 8s linear infinite`) та базове автообертання полотна працюють безперервно. Користувачі з вестибулярними розладами не можуть вимкнути їх системним налаштуванням.
6. **Конфлікти гарячих клавіш (WCAG 2.1.4):**
   - Одинарні клавіші `Пробіл` та `R` перехоплюються глобально. Натискання пробілу під час перебування фокусу на кнопці викликає одночасно клік по кнопці та перемикання автоповороту.

## 3. Візуальне шліфування та HUD-стилістика

### 3.1 Гласморфізм та кіберпанк-естетика
- **Межі та симуляція світла:** Поточні панелі мають однорідну пласку рамку завтовшки 1px (`rgba(0, 240, 255, 0.25)`). Для вишуканого гласморфізму рекомендується спрямоване підсвічування: світлий тонкий верхній кант (`border-top: 1px solid rgba(255, 255, 255, 0.2)`) та внутрішня тінь (`box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.1)`).
- **Геометрія у стилі Hi-Tech:** Звичайні заокруглені кути (`border-radius: 8px, 12px`) виглядають стандартно. Використання скошених технологічних кутів (`clip-path`), кутових маркерів-прицілів (`::before` / `::after`) або акцентних насічок надасть інтерфейсу автентичного вигляду кібернетичного термінала.
- **Стилізація скролбара:** Вміст панелі (`.panel-content`) має вертикальне прокручування, проте смуга прокручування не стилізована. На Windows та Linux відображається стандартний сірий скролбар браузера, який порушує темну неонову гармонію.

### 3.2 Елементи керування та повзунки
- **Відображення повзунків у Firefox:** У `css/style.css:382-395` стилізовано лише `-webkit-slider-thumb`. У Firefox потрібен псевдоелемент `::-moz-range-thumb`. Через це у Firefox відображаються стандартні квадратні кнопки ОС.
- **Заповнення шкали повзунка:** Доріжка має однотонний сірий фон. Двоколірна шкала (неоново-блакитна до повзунка та темно-сіра після) робить поточне значення наочним.
- **Інтерактивний відгук перемикачів:** Перемикачам бракує плавного неонового сяйва під час наведення та підсвічування всього рядка під час наведення курсора.
- **Стрілка вибору теми:** Селект `#themeSelect` відображає системну стрілку ОС. Використання `appearance: none;` із векторним SVG-шевроном впише випадний список у загальний стиль.

### 3.3 Типографіка, іконки та компонування
- **Тремтіння цифр у телеметрії:** Значення Pitch, Yaw та FPS під час зміни розрядності змінюють ширину текстового блоку, викликаючи легке посмикування. Рекомендується використовувати `font-variant-numeric: tabular-nums` або моноширинне позиціонування.
- **Системні емодзі у кнопках:** Іконки `↺ RESET`, `📸 SNAPSHOT`, `⛶ FULLSCREEN`, `⚙ SETTINGS` на macOS, Windows та Android відображаються різноколірними системними емодзі. Заміна на векторні SVG-іконки в монохромному неоновому стилі забезпечить цілісний дизайн.

## 4. План рекомендацій та дорожня карта покращень

### Пріоритет 1: Адаптивність та мобільна взаємодія
1. **Реорганізація кнопок швидких дій:**
   - На екранах `< 640px` перевести кнопки в компактний формат (лише іконки) або сітку 2x2.
   - На екранах `< 420px` сховати другорядні кнопки (Знімок, Повний екран) у випадне меню, звільнивши нижню частину екрана для жестів обертання.
   - Впровадити `env(safe-area-inset-bottom)` та `env(safe-area-inset-top)`.
2. **Мобільне спливаюче меню налаштувань:**
   - На мобільних пристроях (`< 600px`) відкривати панель налаштувань у вигляді нижньої шторки (bottom sheet) або бічного висувного меню на весь екран із затемненням фону.
3. **Адаптивна телеметрія:**
   - На планшетах (600px–820px) залишити 2 ключові показники (наприклад, FPS + Zoom) замість повного приховування блоку.

### Пріоритет 2: Повна відповідність стандартам доступності (WCAG AA)
1. **Доступні перемикачі:**
   - Замінити `display: none` у `.toggle-control input` на патерн візуального приховування для збереження доступу по Tab.
   - Додати чіткі кільця фокусу `:focus-visible` для кнопок та перемикачів.
2. **Семантика та ARIA:**
   - Розмітити полотно Canvas, повзунки, випадний список та кнопки атрибутами `aria-label`, `aria-expanded` та `aria-controls`.
3. **Кросбраузерні повзунки:**
   - Додати правила `::-moz-range-thumb` та `::-moz-range-track` для браузера Firefox.
4. **Підтримка prefers-reduced-motion:**
   - Додати медіазапит для зупинки обертання логотипа та вимкнення автоповороту полотна за увімкненої системної опції зниження руху.

### Пріоритет 3: Візуальне шліфування та кіберпанк-оформлення
1. **Технологічні кути та облямівка скла:**
   - Оформити панелі скошеними кутами та світловідбивною верхньою кромкою.
2. **Стилізований неоновий скролбар:**
   - Налаштувати `scrollbar-width: thin` та `::-webkit-scrollbar` у фірмових відтінках Cyan / Dark Navy.
3. **Векторні монохромні іконки:**
   - Замінити системні емодзі чистими SVG-гліфами в єдиній колірній гамі `--accent-cyan`.
4. **Індикація прогресу на шкалах:**
   - Реалізувати двоколірне підсвічування пройденого шляху повзунка.
5. **Обмеження щільності пікселів на 4K:**
   - Обмежити DPR значенням `Math.min(window.devicePixelRatio || 1, 2)` у `renderer.js` для збереження стабільних 60 FPS на екранах високої чіткості.
