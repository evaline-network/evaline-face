# Отчёт: Эстетическая 3D-скульптура женского лица и публикация репозитория на GitHub

## Обзор
В данном техническом отчёте зафиксированы результаты процедуры скульптурирования элегантной минималистичной женской 3D-топологии лица, а также процесс инициализации и публикации проекта на GitHub.

## 1. Анатомическая 3D-скульптура женского лица (`js/faceData.js`)

468 3D-вершин канонической модели лица были алгоритмически модифицированы для достижения утончённых женских пропорций с сохранением исходной топологии:

1. **Изящная V-образная линия подбородка и челюсти ($y < -0.2$):**
   - Применено квадратичное сужение контура:
     $$\text{taper} = 1.0 - 0.16 \cdot (t^{1.3})$$
   - Сглажены упрямые углы челюсти и сформирован изящный V-line подбородок.

2. **Высокие подтянутые скулы ($0.05 < y < 0.45, |x| > 0.25$):**
   - Усилен скульптурный изгиб скуловой дуги:
     $$\Delta x = 0.07 \cdot \sin\left(\frac{y - 0.05}{0.4} \pi\right)$$
   - Приподнята высота скул с легким выдвижением вперёд.

3. **Утончённая спинка и кончик носа ($|x| < 0.2, -0.25 < y < 0.35$):**
   - Переносица сделана более аккуратной и узкой на $14\%$ ($x \leftarrow x \times 0.86$).
   - Сформирован изящный аккуратный кончик носа ($z \leftarrow z + 0.02$).

4. **Объёмные губы с дугой Купидона (Landmarks губ):**
   - Увеличен объём и проекция губ вперёд ($z \leftarrow z + 0.035$).
   - Выделен изгиб дуги Купидона на верхней губе ($y \leftarrow y + 0.015$).

5. **Миндалевидный разрез глаз (Outer Eye Landmarks):**
   - Приподняты внешние уголки глаз (индексы 33, 263, 130, 359) на $+0.02$ по оси $Y$ и $+0.015$ по оси $Z$.
