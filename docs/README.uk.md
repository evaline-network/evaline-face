# Інтерактивна 3D-модель обличчя на чистому JavaScript (Vanilla JS)

Високопродуктивна інтерактивна 3D-модель людського обличчя, що візуалізується в реальному часі за допомогою чистого ванільного JavaScript та HTML5 Canvas 2D API. Проєкт функціонує абсолютно без зовнішніх бібліотек, фреймворків чи 3D-рушіїв (без Three.js, Babylon.js та без WebGL залежностей).

## Основні можливості

- **Анатомічна 3D-топологія обличчя**: базується на канонічній моделі обличчя людини з 468 вершинами та 898 трикутними полігонами.
- **3D-рушій на чистому Vanilla JS**:
  - Перспективна проекція камери з урахуванням фокусної відстані та глибини.
  - Матриці 3D-обертання за кутами Ейлера та кватерніонами.
  - Обчислення нормалей до площин трикутників для спрямованого освітлення за Ламбертом.
  - Глибинне сортування (Painter's algorithm) для коректного накладання полігонів.
  - Відсікання невидимих граней (back-face culling) для перемикання між суцільною поверхнею та напівпрозорою голограмою.
- **Три основні режими візуалізації**:
  1. **Точки (вершини)**: 468 неонових точок із масштабуванням за глибиною та акцентним виділенням очей, губ і контуру носа.
  2. **Дротяний каркас (ребра)**: згладжені лінії трикутної сітки з регульованою товщиною та неоновим сяйвом.
  3. **Полігони (трикутні грані)**: напівпрозорі трикутники, відсортовані за глибиною, із динамічним дифузним освітленням.
- **Інтерактивне керування камерою (Orbit Controls)**:
  - Обертання лівою кнопкою миші / одним пальцем на сенсорному екрані з плавною інерцією.
  - Масштабування коліщатком миші або жестом pinch-to-zoom.
  - Панорамування правою кнопкою миші або Shift + ліва кнопка.
  - Подвійний клік або клавіша `R` — скидання камери у вихідне положення.
  - Пробіл — увімкнення/вимкнення плавного авто-обертання.
- **5 вбудованих колірних Sci-Fi палітр**:
  - *Cyberpunk Neon* (бірюзовий та неоново-рожевий)
  - *Matrix Emerald* (смарагдово-зелений та лаймовий)
  - *Electric Sci-Fi Blue* (електричний синій та крижаний)
  - *Solar Amber* (бурштинове золото та помаранчевий)
  - *Titanium Silver* (мінімалістичний титановий білий)
- **Підтримка екранів Retina / High-DPI**: бездоганна чіткість ліній та точок на будь-яких екранах.
- **Повна автономність**: 100% офлайн робота в будь-якому сучасному браузері без звернення до мережі.

## Структура проєкту

```
evaline-face/
├── index.html           # Повноекранний канвас і плаваючий HUD інтерфейс
├── css/
│   └── style.css        # Футуристичний кіберпанк дизайн та стилізація HUD
├── js/
│   ├── faceData.js      # Канонічні 3D координати (468 вершин, 898 трикутників)
│   ├── math3d.js        # 3D математика: вектори, матриці, проекція, нормалі
│   ├── renderer.js      # Багатошаровий канвас-рендерер (точки, лінії, полігони)
│   ├── controls.js      # Керування мишею і тачем з інерцією та зумом
│   └── app.js           # Головний контролер, цикл рендерингу та події UI
└── docs/
    ├── README.en.md     # Документація англійською мовою
    ├── README.ru.md     # Документація російською мовою
    └── README.uk.md     # Документація українською мовою
```

## Запуск проєкту

1. Відкрийте файл `index.html` безпосередньо в будь-якому сучасному браузері, або:
2. Запустіть локальний вебсервер:
   ```bash
   python3 -m http.server 8080
   # або
   npx serve .
   ```
3. Перейдіть за адресою `http://localhost:8080`.
